# Contributing to Lishan Foundation

Thank you for your interest in contributing to Lishan Foundation! We build open-source tools, assistive interfaces, and ecological systems for the public good across our two main tracks: **OpenHuman** and **OpenNature**.

## How to Contribute

### 1. Reporting Bugs & Suggesting Features
* Check existing issues and pull requests before creating a new one to avoid duplicates.
* Use our issue templates for [Bug Reports](.github/ISSUE_TEMPLATE/bug_report.md) and [Feature Requests](.github/ISSUE_TEMPLATE/feature_request.md).
* For broad architectural questions, start a thread in **Discussions** rather than opening an issue.

### 2. Submitting Code (Pull Requests)

1. **Fork the repository** you want to contribute to and clone it locally.
2. **Create a branch** off `main` with a descriptive name:
   ```bash
   git checkout -b fix/issue-description
   # or
   git checkout -b feat/feature-name
